# Crometium TCG — Multilingua (i18n)

Crometium TCG è **multilingua** dalla v0.8: l’UI e molti messaggi del background usano cataloghi JSON, non stringhe fisse.

## Lingue supportate

| Codice | Lingua | File |
|---|---|---|
| `it` | Italiano (default) | `locales/it.json` |
| `en` | English (fallback) | `locales/en.json` |
| `es` | Español | `locales/es.json` |

Costanti in `i18n.js`:

```js
export const SUPPORTED = ["it", "es", "en"];
export const DEFAULT_LOCALE = "it";
export const FALLBACK_LOCALE = "en";
```

## Come sceglie la lingua

1. Se esiste `chrome.storage.local.locale` → usa quella.
2. Altrimenti rileva `navigator.language` (`it*` / `en*` / `es*`).
3. Se non riconosciuta → `it`.
4. Chiave mancante nel catalogo attivo → prova `en` → altrimenti mostra la chiave grezza.

L’utente può cambiare lingua dal tab **Impostazioni** (`#localeSelect`). Il cambio aggiorna storage e riallinea popup / watchlist in tempo reale (`onLocaleChange`).

## Motore (`i18n.js`)

| API | Uso |
|---|---|
| `init()` | Carica catalogo all’avvio (popup, watchlist, background) |
| `t(key, params?)` | Traduce; placeholder `{name}` sostituiti da `params` |
| `applyDom()` | Applica `data-i18n`, `data-i18n-placeholder`, `data-i18n-title` |
| `setLocale(code)` | Salva e ricarica messaggi |
| `getLocale()` / `getLocaleBcp47()` | Codice corrente / tag BCP47 per date |
| `onLocaleChange(fn)` | Callback su cambio lingua |

Esempio HTML:

```html
<h3 data-i18n="app.title">Crometium TCG</h3>
<input data-i18n-placeholder="add.blueprintPlaceholder">
<button data-i18n-title="chart.close" title="Chiudi">✕</button>
```

Esempio JS:

```js
t("chart.stats.zero", { price: "€1.20", delta: "+€0.10" });
```

## Dove si usa

- **popup.js / watchlist.js**: titoli, tab, form, stats grafico, status.
- **background.js**: testi notifiche / messaggi di stato (dopo `initI18n()`).
- **manifest.json**: `name` / `description` sono fissi (Chrome non carica i cataloghi custom come `_locales` standard); la UI interna resta tradotta.

## Aggiungere una lingua (es. `fr`)

1. Copia `locales/en.json` → `locales/fr.json` e traduci i valori.
2. Aggiungi `"fr"` a `SUPPORTED` in `i18n.js`.
3. Aggiungi mapping BCP47 (`fr-FR`) e branch in `detectBrowserLocale()`.
4. Aggiungi `<option value="fr">` nel select lingua del popup + chiave `lang.fr` nei cataloghi.
5. Verifica popup, watchlist e una notifica di alert.

## Convenzioni chiavi

Prefissi usati nei JSON:

- `app.*` — nome prodotto
- `tabs.*`, `add.*`, `list.*`, `settings.*` — UI popup
- `chart.*` — grafici
- `watchlist.*` — pagina dedicata
- `channel.*` — Zero / Normale
- `status.*`, `alert.*`, `bg.*` — feedback e background
- `badge.*`, `card.*` — badge lista (auto-cart, qty, pausa, Riprendi)
- `lang.*` — etichette delle lingue nel selettore

Mantieni le **stesse chiavi** in tutti i file lingua; cambia solo i valori.

Chiavi finish recenti: `add.cardFinish`, `add.finishFoil` / `finishNonfoil` / `finishReverse`, `add.foilHint`, `bg.cartAddedQty`, `bg.cartPaused`, `badge.qtyProgress`, `badge.paused`, `card.resume`.
